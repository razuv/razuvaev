# Portfolio admin

Панель управления контентом портфолио. Читает настройки из `VITE_SETTINGS_URL`, а обновления отправляет в `VITE_API_URL`.

```bash
cp .env.example .env
npm ci
npm run dev
npm run build
```

## Редактор кейсов

Редактор автоматически сохраняет черновики через защищённый `GET/PUT /api/project-workspace`.
Публичный `/api/settings` продолжает возвращать опубликованные данные. Кнопка
«Опубликовать изменения» открывает обзор и публикует **все кейсы во всех языках** одной
транзакцией. Названия, обложки и пароли NDA проверяются перед публикацией.

API и админку нужно обновлять вместе. Новые подписи, скрытие блоков, роли участников
и контекст метрик требуют также обновления UI. Таблица `project_workspace` создаётся
автоматически в существующей SQLite-базе. Перед обновлением сохраните резервную копию
базы. При первом открытии редактора legacy-проекты получают постоянные ID на основе
существующего позиционного соответствия переводов; тексты при этом не переписываются.
Если порядок переводов уже различался до обновления, сначала восстановите соответствие.

Структура, порядок проектов, оформление и доступ общие для всех языков; тексты отдельные.
Медиа блока можно сделать локальными, выключив «Одинаковые медиа во всех языках».
Предпросмотр использует компонент публичного сайта внутри изолированного iframe.
Отмена/повтор доступны в текущем сеансе. Раздел «История» сохраняет версии в SQLite
с датой и временем после сохранения контента и черновиков или публикации кейсов.
Восстановление заменяет данные выбранного раздела и само добавляется в историю.
История начинается с первого сохранения после обновления: предыдущие версии базы
задним числом не создаются.
При конфликте другой вкладки изменения не перезаписываются: можно скачать резервную
копию текущего черновика и обновить редактор.

Для изолированной проверки можно направить админку на тестовый API:

```bash
VITE_DEV_API_URL=http://127.0.0.1:3100 npm run dev
```

Точечные регрессионные проверки:

```bash
node --experimental-strip-types --test scripts/case-editor.test.mjs
npm run build --prefix api
node --test api/test/project-workspace.test.mjs
```

Последние команды выполняются из корня репозитория.
